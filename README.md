# Tibau Clarysse Portfolio - WebStorm version

This is a standalone HTML/CSS/JavaScript recreation of the Webnode portfolio.

## Open in WebStorm
1. Extract the ZIP.
2. Open the extracted `tibau-webstorm` folder in WebStorm.
3. Open `index.html` in a browser, or use WebStorm's built-in preview.

## Structure
- `index.html` - Home
- `about.html` - About me
- `projects.html` - Projects
- `contact.html` - Contact
- `css/style.css` - All styling
- `js/script.js` - Mobile navigation behavior
- `images/` - reserved for locally downloaded assets

## Note about images
The recreated pages currently reference the image files from the existing Webnode CDN so the visual content can be used immediately. If you want a completely independent/offline copy, download those images into `images/` and replace the image URLs in the HTML with local paths.

## Project pages
The Projects page now has clickable project images/cards:
- `WIP.html`
- `crash.html`
- `doodle-jump.html`
- `jousted.html`

Each project has its own page, and the cards link to it.
